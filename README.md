# Next.js Financial Dashboard

A responsive full-stack invoice dashboard built with Next.js, React, TypeScript, Tailwind CSS and PostgreSQL.

## Live Demo

**[View the live app](https://nextjs-dashboard-sand-nine-36.vercel.app)**

The dashboard requires a login. Use this public demo account:

- **Email:** `user@nextmail.com`
- **Password:** `123456`

> This is a demo account with sample data, so feel free to create, edit and delete invoices.

## Features

- Secure login and logout, with authenticated routes
- Search invoices, with debounced input to avoid unnecessary requests
- Create, edit and delete invoices
- Monthly bar chart that visualizes invoice data
- Responsive layout for desktop and mobile

## Tech Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · PostgreSQL
